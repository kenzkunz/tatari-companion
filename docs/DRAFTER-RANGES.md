# Drafter tile previews

Added in v1: Settings > Full field / Attack range / Skill range. Range settings are device preferences, separate from saved/shareable formations. Hover/focus a deployed Tatari, hover an empty tile with a selected candidate, or drag a Tatari across the field. Blue solid edges indicate basic attack geometry; orange dashed edges indicate possible skill coverage. Overlaps use both styles. Layers are pointer-transparent and excluded from exported formation images.

Data is derived from v0.49.1 SkillTable and the static client grid consumers. Canonical offsets use positive Y forward; screen rows invert Y. Rectangular bounds are inclusive, distance masks are Manhattan, and manual shapes override masks. Arena cast/effect override groups fall back together when their distance is zero and both arrays empty. The export contains selected derived geometry only. Rebuild with `node scripts/generate-drafter-ranges.mjs <selected-candidate-handoff.json>`; private archives/configuration are not part of this repository.

Stage, Boss and Horde use normal component geometry. Badge Dojo uses the Arena profile and shows the union of possible four-way facing coverage, not a fixed current battle facing. Gold Rush and Other remain explicitly unavailable pending mode verification. Horde skill coverage includes configured skills unlocked at levels3/5/7. Target-centered AoEs union possible affected tiles around valid on-board targets. Self AoEs stay on their caster. This is potential configured coverage, not a prediction that each highlighted tile is hit. Custom scripts, projectile collision, buffs and other runtime range changes are not simulated. No new live-game validation is claimed.

The pale column-four line came from legacy `.board-cell.p2-cell:nth-child(6n+4)` divider rules. Both were removed. Keyboard focus remains visible as an inset white dashed outline, avoiding clipped yellow focus edges.

Validation: source-derived geometry fixtures, all-form board-bound clipping, unsupported-mode behavior, immutability, and off-board target exclusion; full site test/build. Chromium browser checks exercised settings, full field, candidate/field hover, mouse movement, real CDP touch movement, unit editing, chip isolation, mobile layout and disabled overlays. The P2 column-four computed border now matches the other edges. Physical mobile Safari has not been tested.

Skill range is currently hidden and forcibly disabled, including previously saved preferences. Its dataset and geometry code are retained for later per-Tatari review. Attack range remains available for verification.
