# Evolution Trial requirements

The website stores evolution requirements in the shared Tatari roster. Requirements include star thresholds, support Tatari, food, event tasks and alternate progress routes.

Alternate tasks remain alternatives. The planner lists missing requirements and estimates star-copy costs; it does not perform an evolution in game. Missing artwork uses a fallback icon without omitting the requirement text.

Changes must preserve requirement identities and saved progress. Validate updates with `node scripts/evolution-planner-check.mjs` and `npm test`.
